# Annotation Dataset Preparation Tool

Python-based utility for extracting frames from videos and preparing annotation-ready multimedia datasets for computer vision workflows.

## Features
- Video frame extraction
- Automated dataset preparation
- Frame sampling for reduced redundancy
- Annotation workflow support

## Technologies Used
- Python
- OpenCV

## Workflow
Video → Frame Extraction → Annotation-Ready Dataset

## Use Case
Designed for AI/ML dataset preprocessing and annotation workflows such as CVAT and computer vision research pipelines.
