# Egocentric Video Dataset Preparation Tool

Python-based utility for extracting frames from videos and preparing multimedia datasets for annotation workflows.

## Features
- Video frame extraction
- Annotation-ready dataset generation
- Automated frame saving
- Multimedia preprocessing pipeline

## Technologies Used
- Python
- OpenCV

## Use Case
Designed for AI/ML dataset preparation and computer vision annotation workflows such as CVAT.
